Intra NOM-035 — Guía de instalación local

Corre el sistema completo en tu máquina usando Docker.

Lo único que necesitas tener instalado:
  • Docker Desktop (Windows / Mac / Linux) — incluye Docker Compose
  • Git — para clonar el repositorio
1
Clona el repositorio

Abre una terminal y ejecuta:

git clone <URL-del-repositorio>
cd NOM035
2
Crea el archivo .env

Copia el archivo de ejemplo y renómbralo:

# En Windows (PowerShell)
copy .env.example .env

# En Mac / Linux
cp .env.example .env

Abre el archivo .env con cualquier editor y ajusta al menos estas tres líneas:

Variable Valor para desarrollo local
DB_PASSWORD Escribe cualquier contraseña, p. ej. mi_password_local
DJANGO_SECRET_KEY Cualquier cadena larga de texto aleatorio
DATABASE_URL Deja el que ya trae, solo reemplaza la contraseña que pusiste arriba en el lugar correspondiente
Ejemplo de DATABASE_URL:
postgres://intra:mi_password_local@db:5432/intra_nom035
Nota que el host es db (el nombre del servicio en Docker), no localhost.
3
Levanta todos los servicios

Desde la carpeta raíz del proyecto, ejecuta:

docker compose up --build

La primera vez esto descarga imágenes y construye el proyecto; puede tardar 5–10 minutos. Las siguientes veces será mucho más rápido.

Verás logs de los cuatro servicios: db, redis, backend y frontend. El sistema estará listo cuando veas algo como
[backend] Booting worker with pid: ... y [frontend] nginx: ready
4
Abre el sistema en tu navegador
Servicios disponibles:
App web: http://localhost:8080
API (Django): http://localhost:8000/api/v1/
Admin Django: http://localhost:8000/admin/
Opcionales
A
Crear un usuario administrador

Con el sistema corriendo, abre otra terminal y ejecuta:

docker compose exec backend python manage.py createsuperuser

Te pedirá correo y contraseña. Luego entra con ese usuario en http://localhost:8080.

B
Detener el sistema

Para detener sin borrar datos, presiona Ctrl + C en la terminal donde está corriendo, o ejecuta en otra terminal:

docker compose down

Para borrar también la base de datos y empezar desde cero:

docker compose down -v
C
Volver a levantar (después de haberlo detenido)

Si no hubo cambios en el código:

docker compose up

Si hubo cambios en el código y necesitas reconstruir:

docker compose up --build
